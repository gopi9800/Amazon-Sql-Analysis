# Amazon E-Commerce Analysis — PostgreSQL

## Overview

This project uses PostgreSQL to analyze an e-commerce business across
customers, products, categories, sellers, orders, payments, shipping,
returns, and inventory.

The analysis focuses on solving practical business problems using
advanced SQL techniques rather than performing only basic data
exploration.

## Business Objectives

The project addresses business questions related to:

- Product and category sales performance
- Customer purchasing behavior
- Customer lifetime value
- Seller performance
- Inventory stock levels
- Shipping performance
- Payment success rates
- Product returns
- Customer segmentation
- Revenue trends
- Year-over-year product revenue changes

## Analysis Performed

### Sales & Product Analysis

- Top-selling products by sales value
- Revenue generated by product category
- Category contribution to total revenue
- Monthly sales trends
- Products experiencing declining revenue

### Customer Analysis

- Average Order Value (AOV)
- Customers with no purchases
- Customer Lifetime Value (CLTV)
- New vs returning customer classification
- Top customers by state

### Seller Analysis

- Top-performing sellers
- Delivered vs cancelled orders
- Inactive sellers
- Seller sales performance

### Inventory Analysis

- Products with low stock levels
- Warehouse-level inventory information
- Inventory stock monitoring

### Shipping & Payment Analysis

- Shipping delays
- Revenue by shipping provider
- Orders handled by shipping provider
- Average delivery time
- Payment status and payment success rate

### Returns Analysis

- Most returned products
- Product return rates
- Customer return behavior

## SQL Techniques Used

The project demonstrates:

- Primary Keys and Foreign Keys
- INNER JOIN and LEFT JOIN
- GROUP BY and HAVING
- Aggregate Functions
- CASE Statements
- Common Table Expressions (CTEs)
- Subqueries
- Window Functions
- RANK()
- DENSE_RANK()
- LAG()
- Date and Time Functions
- Conditional Aggregation
- Revenue and KPI calculations
- Year-over-Year Analysis
- Customer Segmentation
- PostgreSQL Functions / Stored Procedures

## Database Structure

The database consists of the following tables:

- `category`
- `customers`
- `seller`
- `products`
- `orders`
- `order_items`
- `payments`
- `shippings`
- `inventory`

The tables are connected using primary and foreign key relationships
to represent the relationships between customers, orders, products,
sellers, payments, shipping, and inventory.
